## The engraving of Kelvin's machine

*Appareil combinateur d'ondes (tide predicter de lord Kelvin, réduit au cas de
quatre ondes seulement)*: Lord Kelvin's tide-predicting machine, cut down to
four waves. Each crank turns one wave, a single string passing over the
pulleys adds them up and a pencil draws the sum on paper rolls. Kelvin's
machine added waves to draw a curve. This project starts from the curve and
finds the waves.

It comes from G. Clerc-Rampal, *La Mer : la mer dans la nature, la mer et
l'homme*, Paris, Librairie Larousse, 1913, page 90. The image is in the public
domain and was taken from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:FMIB_36872_Appereil_Combinateur_d%27Ondes_(Tide_Predicter_de_Lord_Kelvin,_Reduit_au_Cas_de_Quatre_Ondes_Seulement).jpeg),
which holds the copy of the Freshwater and Marine Image Bank of the University
of Washington (accession number 36872).
