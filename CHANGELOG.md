# Changelog

## Unreleased

- `autostat.smc`: AutoGP.jl (ICML 2023) ported to Python. Sequential Monte
  Carlo over kernel structures, subtree-replace and detach-attach moves,
  HMC, online `add_data`, mixture forecasts. Checked against AutoGP.jl
  v0.1.19 through `juliacall` (`tests/test_smc_julia.py`): densities,
  covariances, move ratios and predictions agree to 3e-12 or better.
- AutoGP.jl's HMC turns out to move the kernel parameters by the gradient of
  the prior alone. The port reproduces this by default.
  `HMCConfig(gradient="full")` gives the sampler the authors intended.
- Extrapolation benchmark: the paper's table recomputed from the published
  2014 forecasts, then the methods of 2026 scored on the same thirteen
  series, family by family.
- PySR and gplearn scored beside Eureqa in that benchmark. PySR stays bounded
  on the series where Eureqa fails (4.56 against 590.55). Operon's macOS
  wheel does not load, so the benchmark records its failures.
- Benchmark data stored as Parquet and rebuilt from the original repository
  by `benchmark/make_parquet.py`, which first checks the SHA-256 of every
  upstream file.
- LightGBM and the neuralforecast models tuned per series by rolling-origin
  cross-validation on the training part (skrub grid, skore evaluation).
- Report figures drawn as SVG by `sprezzature-figures` (its
  `gaussian-process` kind, handed the posterior computed here) in place of
  matplotlib PNGs. The fonts stay outside the file, so a figure weighs about
  40 kB.
- `examples/`: one script per example of EXAMPLES.md, beside the reports it
  writes in Markdown and in LaTeX. The thirteen published 2014 models get
  their reports there too. PySR found a formula within 1 % for 4 of the 13
  smooth components it tried.
- Reports in Markdown compiled to PDF by md2star, or in LaTeX compiled by
  `latexmk`: `describe(..., report_format=)`, `autostat --format`.
- Five surfaces over one service layer (`autostat.service`):
  - The command line moves to Click (`--format`, `--pdf/--no-pdf`), where
    `--help` and `--version` now return 0 from `main` instead of raising.
  - `autostat-gui` is a form generated by sprezzature-cli-gui that runs on
    127.0.0.1, with its strings in `locales/i18n.yaml`.
  - An HTTP API (`autostat.api`, FastAPI).
  - An MCP server (`autostat-mcp`, FastAPI-MCP, four allowlisted tools).
  - An Agent Skill (`skills/autostat`) routed by `TRIGGERS.md`.
- The GUI loads nothing from another host. sprezzature-cli-gui embeds
  Tailwind's Play build, fetched from its CDN once when the page is generated
  and cached locally. The form leaves out `--version` and `--json`.
- Every report states the formula the search found (`autostat.formula`,
  `Report.formula()`). The model is written as a sum of components, each
  component's covariance with its fitted parameters, changes of regime
  defined once. Every polynomial component, switched or not, also gets a
  closed form: the airline trend is `92.68 + 31.58 (t - 1949)`, the solar
  Maunder-minimum offset `-0.5964 w_1(t)`.
- Reports open on the data and follow the search level by level.
  `Experiment.patience` searches on past the level where BIC stops falling,
  so the report shows what going further would have found.
- `autostat.plausibility` weighs each structure by exp(-BIC/2) times a
  prior, normalised, beside its description length, after the Bayesian
  machine scientist. A prior learned from a corpus by maximum entropy stays
  experimental: on a pool the grammar reaches in two steps, it favours
  complexity.
- Every report says how much the data prefer the kept structure. Under a
  flat prior, the search path gives the posterior weight of the kept
  structure and of the next one. It tabulates the weights, then reads them in
  one of three sentences: the data barely tell the two apart, favour the kept one without ruling
  the next out, or give it almost all the weight.
- The BIC curve appears wherever BIC has something to show. A search of one
  level gets a sentence instead of a curve. An AutoGP summary has no levels,
  so it draws each structure's BIC above the lowest and says whether BIC
  ranks the structures as the posterior does. The skill's report check knows
  the AutoGP summary and accepts an absence the report explains.
- Generated reports are signed "Some Math empowered by some AI guided by some
  researchers" (`REPORT_AUTHOR`): YAML front matter in Markdown, `\author` in
  LaTeX. The project itself stays signed Warith Harchaoui.
- `assets/`: the project's logo with its variants (sizes, favicons, icons,
  social card) and a public-domain 1913 engraving of Kelvin's tide machine.
  The logo heads the README and the LISEZMOI.
- README, LISEZMOI, EXAMPLES and EXEMPLES rewritten to the project's writing
  charter, with the facts brought up to date.
- `doc/`: a technical report on the repository with a state of the art and
  65 verified references, in Markdown (md2star) and LaTeX (generated by
  Pandoc), built by `doc/build.sh`.
- Examples 3 and 6 search the full ten levels: BIC kept improving until the
  ninth level on both.
- The API and the MCP tools return the formula and the search path. They take
  `patience` and `symbolic`. The GUI builds its page once per host.
- The Agent Skill follows Anthropic's skills guide: no `<` or `>` in its
  frontmatter, worked examples, a validation script, a set of trigger
  queries, a zip built by `scripts/build_skill.py`. `tests/test_skill.py`
  holds the rules.
- Every module and function has a NumPy-style docstring. Every module is
  signed `warithmetics@deraison.ai`.

## 0.1.0, 7 November 2026

First release.

- Port of the 2014 Automatic Bayesian Covariance Discovery (ABCD) system to
  Python 3 and `torch`: kernels, grammar, greedy search, decomposition,
  English report.
- The configuration of the 2013 compositional kernel search, as a preset.
- Model checking (QQ plots, autocorrelation, periodogram, MMD) ported from the
  original's MATLAB code.
- The thirteen benchmark series and the 2014 results, with a test that
  re-scores all 130 published models.
- The command line `autostat`, with `--preset`, `--json` and `--no-check`.
