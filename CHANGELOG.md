# Changelog

## Unreleased

- `autostat.smc`: AutoGP.jl (ICML 2023) ported to Python. Sequential Monte
  Carlo over kernel structures, subtree-replace and detach-attach moves,
  HMC, online `add_data`, mixture forecasts. Checked against AutoGP.jl
  v0.1.19 through `juliacall` (`tests/test_smc_julia.py`): densities,
  covariances, move ratios and predictions agree to 1e-12 or better.
- Found that AutoGP.jl's HMC moves kernel parameters by the prior gradient
  only; reproduced by default, `HMCConfig(gradient="full")` for the
  intended sampler.
- Extrapolation benchmark: the paper's table recomputed from the published
  2014 forecasts; the methods of 2026 are scored on the same thirteen
  series, family by family.
- Benchmark data stored as Parquet, rebuilt from the original repository
  by `benchmark/make_parquet.py`, which checks the SHA-256 of every
  upstream file first.
- LightGBM and the neuralforecast models tuned per series by rolling-origin
  cross-validation on the training part (skrub grid, skore evaluation).
- Report figures drawn as SVG by `sprezzature-figures` (its
  `gaussian-process` kind, handed the posterior computed here) in place of
  matplotlib PNGs. The fonts are not embedded, so a figure weighs about
  40 kB.
- `examples/`: one script per example of EXAMPLES.md with the reports it
  writes, in Markdown and in LaTeX; the thirteen published 2014 models are
  described there too.
- Reports in Markdown compiled to PDF by md2star, or in LaTeX compiled by
  `latexmk`: `describe(..., report_format=)`, `autostat --format`.
- Five surfaces over one service layer (`autostat.service`): the command
  line moves to Click (`--format`, `--pdf/--no-pdf`; `--help` and
  `--version` now return 0 from `main` rather than raising); `autostat-gui`,
  a form generated by sprezzature-cli-gui that runs on 127.0.0.1, its
  strings in `locales/i18n.yaml`; an HTTP API (`autostat.api`, FastAPI);
  an MCP server (`autostat-mcp`, FastAPI-MCP, four allowlisted tools); an
  Agent Skill (`skills/autostat`) routed by `TRIGGERS.md`.
- The GUI loads nothing from another host: sprezzature-cli-gui embeds
  Tailwind's Play build, the current release fetched from its CDN when the
  page is generated and cached locally. The form drops `--version` and
  `--json`.
- Every report states the formula the search found (`autostat.formula`,
  `Report.formula()`): the model as a sum of components, each component's
  covariance written out with its fitted parameters, changes of regime
  defined once, plus a closed form for every component that is a polynomial,
  switched or not (the airline trend, `92.68 + 31.58 (t - 1949)`; the solar
  Maunder-minimum offset, `-0.5964 w_1(t)`).
- `doc/`: a technical report on the repository with a state of the art and
  65 verified references, in Markdown (md2star) and LaTeX (generated by
  Pandoc), built by `doc/build.sh`.
- Examples 3 and 6 search the full ten levels: the BIC improved until the
  ninth level on both.
- The API and the MCP tools return the formula and the search path; they take
  `patience` and `symbolic`. The GUI builds its page once per host.
- The Agent Skill follows Anthropic's skills guide: `<` and `>` out of its
  frontmatter, examples, a validation script, a set of trigger queries, a zip
  built by `scripts/build_skill.py`, rules held by `tests/test_skill.py`.
- Every module and function carries a NumPy-style docstring; modules are
  signed `warithmetics@deraison.ai`.

## 0.1.0, 7 November 2026

First release.

- Port of the 2014 Automatic Bayesian Covariance Discovery (ABCD) system to
  Python 3 and `torch`: kernels, grammar, greedy search, decomposition,
  English report.
- The 2013 compositional kernel search configuration as a preset.
- Model checking (QQ, autocorrelation, periodogram, MMD) from the original's
  MATLAB code.
- The thirteen benchmark series and the 2014 results, with a test that
  re-scores all 130 published models.
- Command line `autostat`, with `--preset`, `--json` and `--no-check`.
